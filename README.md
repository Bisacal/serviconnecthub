# ServiConnectHub 🛠️
**Live Demo:** https://serviconnecthub.lovable.app
**Built by Bisacal Tech Enterprise** | Masaka, Abuja - bisacaltech.com

A marketplace platform connecting Abuja residents with verified professionals: Electricians, Plumbers, Solar Installers, Fashion Designers, Tutors and more.

### 🌟 Features
- Location-based search (by area in Abuja)
- 12 Service Categories
- Client & Provider Authentication
- WhatsApp Integration
- Mobile Responsive

### 💻 Tech Stack
React | TypeScript | Tailwind CSS | Supabase

### 🚀 Vision
Started in Abuja/Masaka, built to scale nationwide across Nigeria.
